Installing

Three steps

  1. DownloadScan the code or tap the button. Use Wi-Fi — the file is about 110 MB.
  2. Allow the installOpen the downloaded file. Android will ask whether to allow installs from your browser; allow it, then confirm.
  3. Open the appChoose a language, then follow the demo sign-in. Type any twelve digits — never a real Aadhaar number — and the one-time code is printed on the screen.

If the install is refused

  1. “App not installed”An older KisanQ build is already on the phone. Uninstall it first, then install again.
  2. No prompt appearsOpen Settings → Apps → Special access → Install unknown apps, and allow your browser.
  3. The link does nothingThe build link expires on 24 November 2026. After that a fresh build is needed.

What you will see

A full procurement round, on demo data

The app connects to a live database holding demo centres and bookings. Booking a slot and watching the queue works end to end on your own phone.

Register

Language, demo Aadhaar and one-time code, then village, crop and preferred centre.

Book

Compare centres on waiting time, remaining buying capacity and the minimum support price for wheat announced for Rabi Marketing Season 2026‑27, ₹2,585 per quintal.

Token

A token number and QR code you can share, and a live count of farmers ahead of you.

Track

Weighing, grading, acceptance and the payment stages, each with the stored figures behind them.

A prototype on demo data. Payments are simulated: stages and amounts are real database records, but no money moves and no bank is connected. KisanQ is an independent student project, not affiliated with or endorsed by any government body. See the full breakdown of what is built and what is not.
