Installing

Three steps

  1. DownloadScan the code or tap the button. Use Wi-Fi — the file is about 110 MB.
  2. Allow the installOpen the downloaded file. Android asks whether to allow installs from your browser; allow it, then confirm.
  3. Open the appPick a language, then the demo sign-in. Type any twelve digits — never a real Aadhaar number — and the one-time code is printed on the screen.

If something goes wrong

  1. “App not installed”An older KisanQ build is already on the phone. Uninstall it, then install again.
  2. No permission promptSettings → Apps → Special access → Install unknown apps, then allow your browser.
  3. The link does nothingThis build link stops working after 24 November 2026 and a fresh build is needed.

What you will see

A full procurement round, on demo data

The app talks to a live database holding demo centres and bookings, so booking a slot and watching the queue works end to end on your own phone.

Register

Language, the demo identity step, then village, crop and preferred centre.

Book

Compare centres on waiting time, remaining buying capacity and the published MSP, then take a slot.

Token

A token number and QR you can share, with a live count of farmers ahead of you.

Track

Weighing, grading, acceptance and payment stages, each with the figures behind them.

A prototype on demo data. Identity verification is simulated and no Aadhaar number is stored. Payment records and stages are simulated — no money moves and no bank or payment system is connected.
